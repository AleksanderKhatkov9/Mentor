# 🎓 Mentor. PHP Backend Development Course

Программа изучения PHP в формате RS School: недели, модули теории, практические задания с баллами, тесты, кросс-чек и отдельный трек задач по алгоритмам.

## 🚀 Overview

- 📣 **Для кого:** с нуля до уровня Junior PHP Developer
- 📅 **Длительность:** 9 недель Stage 0 + 12 недель Stage 1 + 8 недель Stage 2 + 6 недель Stage 3
- ⏱️ **Нагрузка:** 15–25 часов в неделю
- 📚 **Формат:** самостоятельное изучение теории, практические задания, тесты, решение алгоритмов, кросс-чек или ревью ментора
- 🧮 **Оценка:** баллы за задания, тесты и алгоритмы. Порог перехода на следующий этап указан в конце каждого этапа

### 📝 Что будет изучено

#### 📌 Foundations

- Профессия backend-разработчика, как работает веб: HTTP, клиент и сервер, DNS
- Инструменты: терминал, VS Code или PhpStorm, Git и GitHub, Composer
- Установка PHP 8.3+, встроенный сервер, Docker (базово)

#### ⚡ Core PHP

- Типы, операторы, условия, циклы, функции, строки, массивы
- Строгая типизация, исключения, работа с файлами
- Пространства имён, автозагрузка, PSR-1, PSR-4, PSR-12

#### 🧩 OOP & Architecture

- Классы, интерфейсы, абстрактные классы, трейты, enum, readonly
- SOLID, внедрение зависимостей, базовые паттерны
- Тестирование: PHPUnit, моки, TDD

#### 🗄️ Web & Data

- Формы, сессии, cookies, безопасность (XSS, CSRF, SQL-инъекции)
- SQL, MySQL или PostgreSQL, PDO, транзакции, индексы
- REST API, JSON, авторизация

#### 🚀 Framework

- Laravel или Symfony (на выбор)
- ORM, миграции, очереди, тесты, деплой
- Командный финальный проект

#### 🎯 Algorithms & Interview

- Сложность алгоритмов (Big O)
- Структуры данных: массив, стек, очередь, связный список, хеш-таблица, дерево, граф
- Сортировки, поиск, рекурсия, два указателя, скользящее окно, динамическое программирование
- Подготовка к техническому собеседованию

## 🧮 Система оценки

| Тип активности | Как проверяется | Баллы |
| --- | --- | --- |
| Задание по языку | автотесты PHPUnit | 50–100 |
| Проект | кросс-чек или ментор | 100–250 |
| Тест по модулю | самопроверка, нужно ≥ 70% | 10 |
| Алгоритмическая задача | LeetCode, Codewars, автотесты | 5–20 |

Правила:

- Дедлайн каждой недели — воскресенье, 23:59.
- Задание, сданное после дедлайна, оценивается в 50% баллов.
- Все решения лежат в одном репозитории, каждое задание — в отдельной ветке и Pull Request.
- В описании Pull Request: ссылка на задание, скриншот прохождения тестов, самооценка по критериям.

### Шаблон решения

```php
<?php

declare(strict_types=1);

/**
 * LeetCode 1. Two Sum
 * https://leetcode.com/problems/two-sum/
 *
 * Time: O(n), Space: O(n)
 */
function twoSum(array $nums, int $target): array
{
    $seen = [];

    foreach ($nums as $i => $num) {
        $complement = $target - $num;

        if (isset($seen[$complement])) {
            return [$seen[$complement], $i];
        }

        $seen[$num] = $i;
    }

    return [];
}
```

# ❓ FAQ

### Что сделать до старта?

1. Установить PHP 8.3+, Composer, Git, редактор кода.
2. Решить 10 задач Codewars 8 kyu на PHP.
3. Прочитать первые разделы [документации PHP](https://www.php.net/manual/ru/langref.php).

### Что делать, если не успеваю?

Сдать задание после дедлайна за 50% баллов. Алгоритмы можно доделывать в любое время, но баллы за неделю засчитываются только до дедлайна этапа.

### Laravel или Symfony?

Laravel — если интересны продуктовые компании, стартапы и фриланс. Symfony — если интересны крупные проекты и энтерпрайз. Основы PHP из Stage 1 и Stage 2 нужны в обоих случаях.

### Можно ли решать алгоритмы не на PHP?

Нет. Цель трека — уверенно писать на PHP, в том числе на собеседовании.
