# 🎓 Mentor. PHP Backend Course. Preparatory Stage (Stage#0)

Подготовительный этап поможет тем, кто совсем не знаком или мало знаком с программированием и хочет успешно учиться на основном курсе.

## Description

- 📣 Записаться может любой желающий
- 📅 Длительность обучения: 9 недель + 2 недели каникул, 16.11.2026 – 31.01.2027
- ⏱️ Нагрузка: 10–20 часов в неделю
- 📚 Формат: самостоятельное изучение, учёба в группе, общение в чате, задания проверяются через кросс-чек и автоматически
- 📝 В конце этапа оставьте **Feedback** о школе, чтобы мы могли её улучшить. Если вы уходите с курса раньше, по возможности тоже оставьте отзыв с причиной ухода

## FAQ

### Где задавать вопросы?

В общем чате курса.

### Важен ли город проживания? Можно ли пройти курс полностью онлайн?

Город не важен. Все этапы проходят онлайн.

### Можно ли изучать модули и делать проекты заранее?

Да. После прохождения всех модулей подготовительного этапа можно переходить к [Stage 1](../stage1/README.md).

### Можно ли пропустить подготовительный этап?

Да, если вы уже умеете писать на PHP формы, работать с массивами и Git. Чтобы проверить себя, решите [PHP-101](tasks/php-101.md) и задачи [Codewars. Часть #3](modules/codewars/README.md).

### Кто проверяет задания?

- Проекты «CV#3», «Coffee Shop», «Dashboard» проверяются через кросс-чек.
- Задачи Codewars, алгоритмические задачи и PHP-101 проверяются автоматически. Решения нужно сдать до дедлайна.
- «CV#1. Markdown & Git» и «CV#2. HTML, CSS & Git Basics» проверяются автоматически.

### Как проходит кросс-чек?

Описано в модуле [Введение в курс](modules/course-intro/README.md).

### Что делать, если PHP не запускается в терминале на Windows?

Добавить папку с `php.exe` в переменную `PATH` и перезапустить терминал. Подробнее — в модулях [Терминал, VS Code, DevTools](modules/basic-tools/README.md) и [Введение в PHP](modules/php-basics/README.md).

### Можно ли использовать ИИ-ассистентов?

Для объяснения теории — да. Для решения задач Codewars, PHP-101, алгоритмов и проектов — нет.
