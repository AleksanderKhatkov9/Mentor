## Задание

Страница меню из [Coffee Shop#1](./coffee-shop-1.md) строится из данных, а не вручную. Пользователь может фильтровать и сортировать товары.

Теория — в модулях [Условия, циклы и функции](../../modules/control-flow/README.md) и [Массивы](../../modules/arrays/README.md).

## Требования

1. Товары хранятся в файле `data/products.php`, который возвращает массив:

```php
<?php

return [
    ['id' => 1, 'name' => 'Эспрессо', 'category' => 'coffee', 'price' => 150, 'description' => '...', 'image' => 'espresso.jpg'],
    // не меньше 12 товаров в 3 категориях
];
```

2. Функции фильтрации и сортировки лежат в `functions.php`, а не в шаблоне.
3. Фильтр по категории — ссылками: `menu.php?category=coffee`. Ссылка «Все» сбрасывает фильтр.
4. Сортировка — ссылками: `menu.php?sort=price_asc`, `price_desc`, `name`.
5. Фильтр и сортировка работают вместе: `menu.php?category=coffee&sort=price_desc`.
6. Карточка на `menu.php` остаётся карточкой из фрейма Menu в [макете Coffee Shop#1](./coffee-shop-1.md): фото, название, цена, те же цвета и шрифты. Фильтр категорий и сортировка — ссылки над сеткой. Активная категория подсвечена.
