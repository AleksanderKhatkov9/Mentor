## Задание

Сделать сайт кофейни из трёх страниц: главная, меню, контакты. Повторяющиеся части страниц вынести в отдельные PHP-файлы.

Теория — в модулях [Введение в PHP](../../modules/php-basics/README.md), [Основы HTML](../../modules/html-basics/README.md), [Основы CSS](../../modules/css-basics/README.md).

## Структура

```text
stage0/coffee-shop/
├── index.php          # главная
├── menu.php           # меню
├── contacts.php       # контакты
├── templates/
│   ├── header.php     # шапка и навигация
│   └── footer.php     # подвал
├── css/style.css
├── images/
└── README.md
```

## Порядок работы

1. Ветка `coffee-shop-1` от `main`.
2. Сверстать три страницы.
3. Вынести шапку и подвал в `templates/`.
4. Открыть Pull Request `coffee-shop-1` → `main` с самооценкой.

## Как сдать

Запуск проверяется локально: `php -S localhost:8000` в папке проекта. В форму кросс-чека отправить ссылку на Pull Request.

## Критерии оценки

- +20 — три страницы открываются через встроенный сервер без ошибок
- +30 — шапка и подвал подключаются через `require` на всех страницах, HTML шапки не дублируется
- +20 — пункт меню текущей страницы подсвечен. Активный пункт определяется в PHP, например через переменную `$currentPage`
- +10 — в подвале текущий год выводится через `date('Y')`
- +20 — на ширине экрана от 320px нет горизонтальной прокрутки
