## Задание

Сделать личный дашборд расходов: пользователь добавляет траты и видит статистику за месяц.

Теория — все модули подготовительного этапа, особенно [Формы](../modules/forms/README.md), [Файлы и JSON](../modules/files-json/README.md), [Массивы](../modules/arrays/README.md).

## Требования

1. Главная страница `index.php`:
   - форма добавления расхода: сумма, категория (список), дата, комментарий;
   - таблица расходов выбранного месяца;
   - блок статистики.
2. Выбор месяца — через `index.php?month=2026-12`. По умолчанию — текущий месяц.
3. Сортировка таблицы — по дате или сумме, ссылками в заголовках столбцов.
4. Статистика за месяц:
   - общая сумма;
   - сумма по каждой категории и её доля в процентах;
   - самая крупная трата;
   - средний расход в день.
5. Удаление расхода — кнопкой в строке таблицы, через форму с `method="post"`.
6. Расходы хранятся в `data/expenses.json`.

## Пример интерфейса

Дизайн свободный, схема показывает только расположение блоков:

```text
┌──────────────────────────────────────────────────────────────┐
│  Мои расходы                     ◀ Ноябрь 2026 ▶             │
├──────────────────────────────────────────────────────────────┤
│  Добавить расход                                             │
│  Сумма [_____]  Категория [Еда ▼]  Дата [2026-11-10]         │
│  Комментарий [______________________]   [ Добавить ]         │
├──────────────────────────────────────────────────────────────┤
│  Дата ↓       │ Категория  │ Сумма ↕  │ Комментарий │        │
│  2026-11-09   │ Еда        │   450.00 │ Обед        │ [✕]    │
│  2026-11-05   │ Транспорт  │   120.00 │ Метро       │ [✕]    │
│  2026-11-02   │ Жильё      │ 15000.00 │ Аренда      │ [✕]    │
├──────────────────────────────────────────────────────────────┤
│  Статистика за месяц                                         │
│  Всего: 15 570.00        Среднее в день: 519.00              │
│  Самая крупная трата: 15 000.00 (Жильё, 2026-11-02)          │
│                                                              │
│  Жильё       15 000.00   96.3%  ████████████████████         │
│  Еда            450.00    2.9%  █                            │
│  Транспорт      120.00    0.8%                               │
└──────────────────────────────────────────────────────────────┘
```

- ◀ ▶ — ссылки на соседние месяцы, например `index.php?month=2026-10`
- заголовки «Дата» и «Сумма» — ссылки сортировки, например `?month=2026-11&sort=amount`
- ✕ — форма с `method="post"`, которая отправляет `id` расхода в `delete.php`
- полоски долей по категориям — по желанию

Пример записи в `data/expenses.json`:

```json
[
    {
        "id": "6730a1f2c4e1b",
        "amount": 450,
        "category": "Еда",
        "date": "2026-11-09",
        "comment": "Обед"
    }
]
```

## Критерии оценки

- +20 — форма добавления расхода с серверной валидацией: сумма больше 0, категория из списка, корректная дата
- +20 — расходы сохраняются в JSON-файл и читаются из него
- +20 — таблица с сортировкой по дате и сумме
- +20 — фильтр по месяцу
- +30 — статистика: общая сумма, суммы и доли по категориям, самая крупная трата, среднее в день
- +20 — удаление расхода через POST-запрос
- +20 — логика расчётов отделена от шаблонов, все данные пользователя выводятся через `htmlspecialchars`
