## Задание

Доработать вёрстку CV из [CV#2](./cv-2-html-css-git.md) по критериям ниже.

## Порядок работы

1. От ветки `cv-html` создать ветку `cv-cross-check`.
2. Оценить свою работу по критериям, внести исправления.
3. Опубликовать обновлённую страницу на GitHub Pages.
4. Открыть Pull Request `cv-cross-check` → `main` с самооценкой по критериям в описании. Не мержить.

## Как сдать

Отправить ссылку на опубликованную страницу в форму кросс-чека до дедлайна. После дедлайна проверить 3 работы других студентов. Как проходит кросс-чек — в модуле [Введение в курс](../../modules/course-intro/README.md).

## Критерии оценки

- +10 — вёрстка валидна: [W3C Validator](https://validator.w3.org/) выводит «Document checking completed. No errors or warnings to show.»
- +20 — используются семантические теги и заголовки, `h1` на странице один. 2 балла за каждый уникальный семантический тег и заголовок, но не больше 20
- +10 — контент размещён в блоке, который отцентрирован по горизонтали
- +20 — на ширине экрана от 320px нет горизонтальной прокрутки, весь контент сохраняется
- +10 — есть фото или аватар, пропорции не искажены, у изображения есть атрибут `alt`
- +10 — контакты и навыки оформлены списками `ul > li`
- +10 — есть пример кода на PHP с подсветкой синтаксиса
- +10 — есть ссылки на профили GitHub и Codewars, открываются в новой вкладке
