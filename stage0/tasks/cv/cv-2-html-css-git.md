## Задание

Сверстать CV из [CV#1](./cv-1-markdown-git.md) веб-страницей и опубликовать её на GitHub Pages.

Теория — в модулях [Основы HTML](../../modules/html-basics/README.md) и [Основы CSS](../../modules/css-basics/README.md).

## Порядок работы

1. От ветки `cv` создать ветку `cv-html`.
2. Создать файлы `stage0/cv/index.html` и `stage0/cv/style.css`.
3. Перенести в вёрстку все разделы CV.
4. Включить GitHub Pages: Settings → Pages → Branch `cv-html`.
5. Добавить ссылку на опубликованную страницу в `README.md`.
6. Открыть Pull Request `cv-html` → `main`. Не мержить.

## Как сдать

Отправить ссылку на опубликованную страницу и на Pull Request в форму сдачи заданий до дедлайна.

## Критерии оценки

- +40 — страница содержит все разделы CV
- +30 — подключены стили из отдельного файла, используются семантические теги
- +30 — страница опубликована на GitHub Pages, ссылка есть в README
