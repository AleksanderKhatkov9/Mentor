## Задание

Создать резюме в формате Markdown и оформить работу в Git по правилам курса.

Теория — в модуле [Git](../../modules/git/README.md).

## Требования к CV

Файл `stage0/cv.md` содержит разделы:

1. Имя и фамилия — заголовок первого уровня
2. Контакты: email, Telegram, GitHub
3. О себе: цели, почему PHP, сильные стороны
4. Навыки: списком
5. Пример кода: решение любой задачи [Codewars](../../modules/codewars/README.md) на PHP в блоке кода с подсветкой `php`
6. Опыт и проекты (если нет — учебные проекты курса, раздел можно дополнять позже)
7. Образование и курсы
8. Уровень английского

Советы для резюме:

- Пишите кратко и по делу, без лишних прилагательных.
- В разделе «О себе» — 3–5 предложений.
- Навыки — только те, которые реально использовали.

## Требования к репозиторию

1. Создать публичный репозиторий `mentor-php` на GitHub.
2. В ветке `main` — только файл `README.md` с вашим именем и ссылкой на CV.
3. Создать ветку `cv` и в ней файл `stage0/cv.md`.
4. Открыть Pull Request из ветки `cv` в ветку `main`. **Не мержить** Pull Request до проверки.

## Требования к коммитам

- Минимум 3 коммита.
- Сообщения по правилам из модуля [Git](../../modules/git/README.md): `docs: add contacts`, `docs: add code example`.

## Как сдать

Отправить ссылку на Pull Request в форму сдачи заданий до дедлайна.

## Критерии оценки

- +50 — CV содержит все разделы, используются заголовки, списки, ссылки и блок кода
- +50 — выполнены требования к репозиторию, коммитам и Pull Request
