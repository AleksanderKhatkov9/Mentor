# [Stage#0.](../../README.md) Терминал, VS Code, DevTools

## В данном модуле студентам необходимо:

1. Научиться работать в терминале: перемещаться по папкам, создавать и удалять файлы.
2. Понять, что такое переменная окружения `PATH`.
3. Настроить VS Code для работы с PHP.
4. Научиться смотреть HTTP-запросы во вкладке Network в Chrome DevTools.

## Приблизительное время прохождения модуля

Теория: 2 часа
Практика: 2 часа

## Теория

### Терминал

| Действие | Linux / macOS / Git Bash | PowerShell |
| --- | --- | --- |
| Где я | `pwd` | `pwd` |
| Список файлов | `ls -la` | `ls` или `dir` |
| Перейти в папку | `cd projects/mentor-php` | `cd projects\mentor-php` |
| На уровень выше | `cd ..` | `cd ..` |
| Создать папку | `mkdir stage0` | `mkdir stage0` |
| Создать файл | `touch index.php` | `New-Item index.php` |
| Копировать | `cp a.php b.php` | `cp a.php b.php` |
| Переместить, переименовать | `mv a.php src/a.php` | `mv a.php src\a.php` |
| Удалить | `rm a.php` | `rm a.php` |
| Очистить экран | `clear` | `cls` |

- Абсолютный путь начинается от корня диска: `D:\projects\mentor-php` или `/home/user/mentor-php`.
- Относительный путь — от текущей папки: `stage0/cv.md`, `../README.md`.
- `Tab` дописывает имя файла, `↑` повторяет прошлую команду.

### Переменная PATH

Когда вы пишете `php -v`, терминал ищет `php` в папках из переменной `PATH`. Если PHP установлен, но команда не находится, папку с `php.exe` нужно добавить в `PATH` и перезапустить терминал.

На Windows удобно работать в Git Bash (ставится вместе с [Git](https://git-scm.com/download/win)): команды там такие же, как на Linux и macOS.

### VS Code

1. Установить [VS Code](https://code.visualstudio.com/).
2. Установить расширения:
   - **PHP Intelephense** — подсказки, переход к определению, проверка ошибок
   - **PHP Debug** — отладка через Xdebug
   - **EditorConfig** — единые отступы
3. Горячие клавиши:
   - `Ctrl+P` — открыть файл по имени
   - `Ctrl+Shift+P` — палитра команд
   - `` Ctrl+` `` — встроенный терминал
   - `Ctrl+/` — закомментировать строку
   - `Alt+↑ / ↓` — переместить строку
   - `Shift+Alt+F` — отформатировать файл

Альтернатива — [PhpStorm](https://www.jetbrains.com/phpstorm/): платный, но бесплатный для студентов.

### Chrome DevTools

- `F12` — открыть DevTools.
- **Elements** — HTML-код страницы, который пришёл с сервера.
- **Network** — все запросы страницы: метод, URL, статус, заголовки, ответ. Здесь видно, что отправляет форма и что отвечает PHP.
- **Console** — ошибки JavaScript.

Материал: [Chrome DevTools: Network](https://developer.chrome.com/docs/devtools/network?hl=ru) (0.5 часа)

## Практика

1. Только через терминал создать структуру папок `mentor-php/stage0/cv`, перейти в неё, создать файл `index.html`, переименовать его в `cv.html`, удалить.
2. Установить VS Code и расширения из списка.
3. Открыть любой сайт, вкладку Network, обновить страницу. Найти первый запрос: какой у него метод, статус и `Content-Type` ответа.
