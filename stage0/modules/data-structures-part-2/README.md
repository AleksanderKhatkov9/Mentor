# [Stage#0.](../../README.md) Алгоритмы и структуры данных (часть 2)

## Содержание модуля:

1. Познакомимся с бинарным поиском.
2. Разберём рекурсию: базовый случай, шаг рекурсии, стек вызовов.
3. Рассмотрим простые сортировки: пузырьком и выбором.
4. Научимся использовать ассоциативный массив как хеш-таблицу: подсчёт, поиск пар, группировка.

## Приблизительное время прохождения модуля

Теория: 3 часа
Практика: 8 часов

## Теория

1. Прочитать [конспект](./algorithms.md) (1 час)
2. Бхаргава «Грокаем алгоритмы», главы 3–5 (2 часа)

## Практика

Решения кладутся в `stage0/algorithms/part-2/`. Каждая задача — 20 баллов, проверка автотестами.

Внимание!

- Не ожидается, что студенты успеют решить все алгоритмические задачи.
- Запрещено копировать код других студентов (текущего, а также предыдущих наборов).

## Вопросы для самопроверки

1. Почему бинарный поиск работает только на отсортированном массиве?
2. Сколько шагов нужно бинарному поиску для массива из 1 000 000 элементов?
3. Что такое базовый случай рекурсии? Что будет без него?
4. Какая сложность у сортировки пузырьком?
5. Почему поиск ключа в ассоциативном массиве — O(1)?
6. Как решить задачу «есть ли два числа с суммой X» быстрее, чем за O(n²)?
