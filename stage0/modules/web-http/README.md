### Что происходит, когда вы открываете сайт

1. Браузер узнаёт IP-адрес домена через DNS.
2. Устанавливает соединение с сервером по порту 80 (HTTP) или 443 (HTTPS).
3. Отправляет HTTP-запрос.
4. Веб-сервер (Nginx, Apache) передаёт запрос PHP.
5. PHP выполняет скрипт: читает данные, обращается к базе, формирует HTML.
6. Сервер отправляет HTTP-ответ.
7. Браузер отображает HTML и загружает CSS, картинки, скрипты отдельными запросами.

### HTTP-запрос

```http
POST /order.php HTTP/1.1
Host: coffee.local
Content-Type: application/x-www-form-urlencoded

name=Ivan&size=m
```

### HTTP-ответ

```http
HTTP/1.1 302 Found
Location: /thanks.php?order=15
Set-Cookie: PHPSESSID=abc123; HttpOnly
```

### GET и POST

| | GET | POST |
| --- | --- | --- |
| Где данные | в адресе: `/menu.php?category=coffee` | в теле запроса |
| Для чего | получить данные: поиск, фильтр, страница | изменить данные: заказ, регистрация |
| Можно сохранить в закладки | да | нет |
| В PHP | `$_GET['category']` | `$_POST['name']` |
