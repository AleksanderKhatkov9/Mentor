# [Stage#0.](../../README.md) Codewars

## В данном модуле студентам необходимо:

1. Зарегистрироваться на Codewars и выбрать язык PHP.
2. Научиться читать условие задачи, запускать тесты и сдавать решение.
3. Решить три набора задач по возрастанию сложности.

## Как работать с Codewars

1. Зарегистрироваться на [codewars.com](https://www.codewars.com/), в настройках профиля указать Clan: `mentor-php`.
2. Открыть задачу, выбрать язык **PHP**.
3. Прочитать условие и примеры. Нажать **Test** — запустятся примеры. Нажать **Attempt** — запустятся все тесты.
4. Когда все тесты прошли — **Submit**.
5. После сдачи посмотреть решения других участников: это лучший способ узнать новые функции PHP.

Ссылка на профиль Codewars добавляется в CV.

## Правила

- Баллы засчитываются, если задача решена до дедлайна части.
- Нельзя открывать чужие решения до сдачи своего.
- Задачи, решённые раньше на другом языке, нужно решить заново на PHP.
