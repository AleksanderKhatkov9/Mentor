## Теория

### Backend и frontend

- **Frontend** — то, что видит пользователь в браузере: HTML, CSS, JavaScript.
- **Backend** — то, что работает на сервере: принимает запросы, проверяет данные, работает с базой данных, отдаёт HTML или JSON.
- Пример: пользователь нажимает «Оформить заказ». Frontend отправляет форму. Backend проверяет данные, сохраняет заказ в базу, списывает товар со склада, отправляет письмо и возвращает страницу «Спасибо».

### Где используется PHP

- Сайты и CMS: WordPress, 1С-Битрикс, Drupal, Joomla
- Интернет-магазины: WooCommerce, Magento, OpenCart
- Веб-приложения и API на фреймворках [Laravel](https://laravel.com/) и [Symfony](https://symfony.com/)
- Крупные проекты: Wikipedia, Slack (часть backend), Facebook (исторически, сейчас Hack)

### Экосистема

- [php.net](https://www.php.net/manual/ru/) — официальная документация
- [Composer](https://getcomposer.org/) — менеджер пакетов
- [Packagist](https://packagist.org/) — каталог пакетов
- [PHP-FIG](https://www.php-fig.org/) — стандарты PSR: стиль кода, автозагрузка, интерфейсы
- Инструменты качества: PHPUnit, PHPStan, PHP-CS-Fixer

### Уровни разработчиков

| Уровень | Что умеет |
| --- | --- |
| Junior | решает понятные задачи под присмотром: CRUD, формы, исправление багов. Знает язык, ООП, SQL, Git, один фреймворк |
| Middle | самостоятельно решает задачи целиком, проектирует модули, пишет тесты, разбирается в производительности |
| Senior | проектирует архитектуру, принимает технические решения, менторит команду |

### Что спрашивают на собеседовании Junior PHP

- PHP: типы, массивы, функции, ООП, исключения
- SQL: `SELECT`, `JOIN`, `GROUP BY`, индексы
- HTTP: методы, статусы, cookies, сессии
- Безопасность: SQL-инъекции, XSS, CSRF
- Git
- Фреймворк: Laravel или Symfony
- Простая алгоритмическая задача
