# [Stage#0.](../../README.md) Алгоритмы и структуры данных (часть 1)

## Содержание модуля:

1. Познакомимся с характеристикой сложности алгоритма (Big O notation).
2. Познакомимся с простейшими структурами данных: массив и матрица.
3. Рассмотрим типичные задачи с массивами и матрицами.
4. Познакомимся со структурами данных стек и очередь.
5. Рассмотрим решение популярной задачи проверки правильной расстановки скобок.

## Приблизительное время прохождения модуля

Теория: 3 часа
Практика: 8 часов

## Теория

1. Прочитать [конспект](./algorithms.md) (1 час)
2. Бхаргава «Грокаем алгоритмы», главы 1–2 (2 часа)
3. Посмотреть визуализацию сортировок на [VisuAlgo](https://visualgo.net/en/sorting) (0.5 часа)

## Практика

Вам необходимо решить предложенные задачи на PHP. Каждая задача — отдельная функция в папке `stage0/algorithms/` с тестами, которые выдаются вместе с заданием.

Внимание!

- Не ожидается, что студенты успеют решить все алгоритмические задачи.
- Запрещено копировать код других студентов (текущего, а также предыдущих наборов).
- Хорошо подумайте перед сабмитом чужого кода, стоит ли риск быть отчисленным за несколько баллов.

Задачи:

1. [brackets](./tasks.md#1-brackets) — проверка скобок
2. [snake-sort](./tasks.md#2-snake-sort) — обход матрицы змейкой
3. [morse-decoder](./tasks.md#3-morse-decoder) — декодер азбуки Морзе
4. [Codewars. Часть #3](../codewars/README.md)

## Вопросы для самопроверки

1. Что показывает O-нотация?
2. Какая сложность у поиска элемента в неотсортированном массиве?
3. Какая сложность у двух вложенных циклов по одному массиву?
4. Чем стек отличается от очереди?
5. Какие функции PHP работают с массивом как со стеком? А как с очередью?
6. Как стек помогает проверить скобки?
