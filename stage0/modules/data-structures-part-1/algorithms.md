## Что такое алгоритм

Алгоритм — последовательность шагов для решения задачи. Одну задачу можно решить разными алгоритмами, и они будут работать с разной скоростью.

## Сложность алгоритма. Big O

O-нотация показывает, как растёт время работы алгоритма при росте объёма входных данных `n`. Константы и мелкие слагаемые отбрасываются: важен порядок роста.

| Сложность | Название | Пример | n = 1 000 |
| --- | --- | --- | --- |
| O(1) | константная | `$arr[5]`, `isset($map['key'])` | 1 операция |
| O(log n) | логарифмическая | бинарный поиск | ~10 операций |
| O(n) | линейная | один цикл по массиву | 1 000 операций |
| O(n log n) | линейно-логарифмическая | хорошие сортировки, `sort()` | ~10 000 операций |
| O(n²) | квадратичная | два вложенных цикла | 1 000 000 операций |

```php
// O(n): один проход
function findMax(array $numbers): int
{
    $max = $numbers[0];
    foreach ($numbers as $number) {
        if ($number > $max) {
            $max = $number;
        }
    }

    return $max;
}

// O(n²): для каждого элемента — проход по всем остальным
function hasDuplicate(array $numbers): bool
{
    $count = count($numbers);
    for ($i = 0; $i < $count; $i++) {
        for ($j = $i + 1; $j < $count; $j++) {
            if ($numbers[$i] === $numbers[$j]) {
                return true;
            }
        }
    }

    return false;
}

// O(n): то же самое через ассоциативный массив
function hasDuplicateFast(array $numbers): bool
{
    $seen = [];
    foreach ($numbers as $number) {
        if (isset($seen[$number])) {
            return true;
        }
        $seen[$number] = true;
    }

    return false;
}
```

Последний пример — главный приём: ассоциативный массив находит ключ за O(1), поэтому часто позволяет убрать вложенный цикл.

## Массив

В PHP массив хранит элементы по ключам. Доступ по ключу — O(1). Поиск значения без знания ключа (`in_array`) — O(n).

Типичные задачи:

- найти максимум, минимум, сумму — один проход;
- развернуть массив — два указателя с концов навстречу друг другу;
- посчитать, сколько раз встречается каждый элемент, — ассоциативный массив-счётчик.

```php
function reverseArray(array $arr): array
{
    $left = 0;
    $right = count($arr) - 1;

    while ($left < $right) {
        [$arr[$left], $arr[$right]] = [$arr[$right], $arr[$left]];
        $left++;
        $right--;
    }

    return $arr;
}
```

## Матрица

Матрица — массив массивов: `$matrix[$row][$col]`.

```php
$matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
];

echo $matrix[1][2]; // 6: строка 1, столбец 2

// транспонирование: строки становятся столбцами
function transpose(array $matrix): array
{
    $result = [];
    foreach ($matrix as $row => $values) {
        foreach ($values as $col => $value) {
            $result[$col][$row] = $value;
        }
    }

    return $result;
}
```

Обход матрицы размером n × m — O(n · m).

## Стек

Стек работает по правилу LIFO (Last In, First Out): последний добавленный элемент забирается первым. Как стопка тарелок.

Операции: `push` — положить наверх, `pop` — снять верхний, `peek` — посмотреть верхний. Все — O(1).

```php
$stack = [];
array_push($stack, 'a');  // или $stack[] = 'a';
array_push($stack, 'b');
echo array_pop($stack);   // b
echo end($stack);         // a — посмотреть верхний
```

Где встречается: кнопка «Отменить», история браузера «Назад», стек вызовов функций, проверка скобок.

## Очередь

Очередь работает по правилу FIFO (First In, First Out): первый добавленный элемент забирается первым. Как очередь в кассу.

```php
$queue = [];
$queue[] = 'заказ 1';
$queue[] = 'заказ 2';
echo array_shift($queue); // заказ 1
```

`array_shift` в PHP — O(n), потому что перенумеровывает ключи. Для больших очередей используют `SplQueue` — его проходят в Stage 1.

Где встречается: обработка заказов по порядку, очередь задач на сервере, обход графа в ширину.

## Разбор: проверка скобок

Задача: строка `([]{})` — правильная, `([)]` — нет.

Идея: идём по строке. Открывающую скобку кладём в стек. Закрывающая должна совпасть с верхней скобкой стека — тогда снимаем её. В конце стек должен быть пустым.

```php
function isBalanced(string $str): bool
{
    $pairs = [')' => '(', ']' => '[', '}' => '{'];
    $stack = [];

    foreach (str_split($str) as $char) {
        if (in_array($char, $pairs, true)) {
            $stack[] = $char;
        } elseif (isset($pairs[$char])) {
            if (array_pop($stack) !== $pairs[$char]) {
                return false;
            }
        }
    }

    return $stack === [];
}
```

Сложность — O(n): один проход по строке, операции со стеком — O(1).
