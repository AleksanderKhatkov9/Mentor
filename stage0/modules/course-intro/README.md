# [Stage#0.](../../README.md) Введение в курс

## В данном модуле студентам необходимо:

1. Узнать, как устроен курс: этапы, недели, дедлайны и баллы.
2. Понять, как сдавать задания: репозиторий, ветки, Pull Request.
3. Узнать, как проходит кросс-чек и автоматическая проверка.
4. Найти, где задавать вопросы.

## Приблизительное время прохождения модуля

Теория: 1 час

## Теория

1. Прочитать [общее описание курса](../../../README.md): этапы, система оценки, структура репозитория, шаблон Pull Request.
2. Прочитать [программу подготовительного этапа](../../README.md) целиком.
3. Прочитать раздел FAQ подготовительного этапа.

### Как устроена учёба

- Каждую неделю — модули с теорией и задания.
- Дедлайн недели — воскресенье, 23:59 по Москве.
- Задание после дедлайна можно сдать в неделю досдачи за 50% баллов.
- Все задания лежат в одном репозитории `mentor-php`, каждое — в своей ветке и Pull Request.

### Как проходит кросс-чек

1. Вы сдаёте ссылку на работу до дедлайна.
2. После дедлайна получаете 3 работы других студентов.
3. Проверяете их по критериям задания и пишете комментарий к каждому снятому баллу.
4. Ваша оценка — среднее от проверяющих.
5. Если вы не проверили свои 3 работы, оценка за задание — 0.

### Правила честной учёбы

- Нельзя копировать код других студентов, в том числе прошлых потоков.
- Нельзя сдавать код, написанный ИИ-ассистентом. Спрашивать у него объяснения теории можно.
- За списывание — 0 баллов за задание, за повторное — отчисление.

## Практика

1. Создать аккаунты на [GitHub](https://github.com/), [Codewars](https://www.codewars.com/) и [LeetCode](https://leetcode.com/).
2. Вступить в чат курса.
3. Пройти тест [St0] Введение в курс: ответить на вопросы ниже.

4. Что запрещено при выполнении заданий?
